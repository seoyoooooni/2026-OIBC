# 팀 작업 규약

이 문서는 예측·채점·배정 코드가 공통으로 따를 데이터 형식과 계산 규칙만 정의한다.

## 공통 데이터 규약

| 항목 | 약속 |
| --- | --- |
| 시각 `ts` | KST 타임존을 포함한 1시간 **우측닫힘** 시각. CSV는 `+09:00` 오프셋을 포함하고, Parquet은 타임존 정보를 유지한다. 타임존 없는 시각은 허용하지 않는다. |
| 운영일 | `(ts - 1시간).date`로 계산한다. 예: `2025-01-01 00:00+09:00`은 2024-12-31의 마지막 시간, `2025-01-01 01:00+09:00`은 2025-01-01의 첫 시간이다. |
| 발전소 키 | `sites.csv`의 `site_id`를 그대로 사용한다. 발전소별 예측의 `(site_id, ts)`는 유일해야 한다. |
| 단위 | 실제·예측 발전량은 해당 **1시간의 kWh**, 설비용량은 kW, SMP는 원/kWh다. 채점 전 예측값을 반올림하지 않는다. |
| 예측 가능 정보 | 대상 운영일 전날 17:00 KST까지 발행된 예보와 그 이전에 알려진 정보만 사용한다. 예측 대상 기간의 실제 발전량·기상 실측·미래 SMP는 예측 특징에 넣지 않는다. 외부 데이터나 외부 데이터로 사전 학습된 모델도 사용하지 않는다. |
| 익명 위치 | 제공된 위경도는 허용된 특징 계산에만 사용한다. 원좌표 복원이나 발전소 재식별을 시도하지 않는다. |
| 집합 | `G1`, `G2`만 사용한다. 253개 발전소를 누락·중복 없이 한 집합에 배정하며, 각 집합 설비용량 합계는 20,000kW 이상이다. |
| 시간대 가중치 `k` | `ts`의 시가 **11~15**이면 3, 그 외는 1이다. `train/smp.csv`에는 `k`가 없으므로 이 규칙으로 생성한다. 평가용 `smp.csv`에는 제공된 `k`를 사용한다. |

## 예측 파일 인계 형식

과거 검증과 최종 평가의 발전소별 예측은 같은 세 열을 사용한다.

| 열 | 뜻 |
| --- | --- |
| `site_id` | 제공된 발전소 ID |
| `ts` | KST 타임존을 포함한 우측닫힘 시각 |
| `pred_kwh` | 해당 발전소의 한 시간 발전량 예측값, 유한한 0 이상의 실수 |

예측 파일에는 이 세 열만 필수로 둔다. 별도 인계 메모에는 **모델 버전, 학습 종료 시점, 예측 기간, 대상 사이트 목록 또는 코호트 정의, 생성 명령, 파일 해시**를 적는다. 인계 전에 이 메모가 선언한 사이트×시각 조합의 완전성, `(site_id, ts)` 중복 없음, `pred_kwh`의 NaN·무한대·음수 없음을 확인한다.

## 채점기 공통 계산 규칙

채점기는 제공된 **원본 발전량 `energy`**를 정답으로 사용한다. 모델 학습을 위해 수정·제외한 정답으로 점수를 계산하지 않는다. 인계 메모가 선언한 대상 사이트·시각과 실제 발전량·SMP를 `(site_id, ts)`로 대조한다. 정답이 없는 키는 0으로 채우거나 조용히 제외하지 않는다. 검증 설정에 유효 사이트·시각 범위를 명시하고, 누락된 키와 제외된 시각을 보고한다. 모든 대상 사이트의 정답이 있는 시각에만 집합 점수를 계산한다.

발전소별 실제값과 예측값을 **먼저 집합·시각별로 합산한 뒤** 절대오차를 계산한다. 채점기는 아래 값을 출력한다.

```text
e[g,t] = 실제 집합 발전량[g,t] - 예측 집합 발전량[g,t]
W = 0.1 × Σ_t SMP[t] × k[t] × (|e[G1,t]| + |e[G2,t]|)
W_바닥 = 0.1 × Σ_t SMP[t] × k[t] × |e[G1,t] + e[G2,t]|
W_분할 = W - W_바닥
S = Σ_t SMP[t] × (실제 발전량[G1,t] + 실제 발전량[G2,t]) - W
```

`W = W_바닥 + W_분할`이 수치 오차 범위에서 성립해야 한다. 제출 배정의 집합별 용량은 각각 20MW 이상이어야 한다.

## 최종 제출 형식 참고

- `composition.csv`: `site_id,group`, 헤더 포함 254행.
- `forecast.csv`: `group,ts,forecast_kwh`, G1·G2 × 평가 8,760시각으로 헤더 포함 17,521행.
- 배정 파일은 253개 ID가 각각 한 번씩 있어야 하고, 예측 파일의 `(group, ts)`는 평가용 `smp.csv`의 모든 시각에 G1/G2가 각각 한 번씩 있어야 한다. 예측값은 유한하고 0 이상이어야 한다.
- 최종 제출 전에 공식 문제정의서의 파일명·열 순서·무효 조건을 다시 확인한다.
